# SKHY(ADR) 프리미엄 추이 대시보드

미국 나스닥(NASDAQ)에 상장된 **SKHY**와 한국 거래소(KRX)의 **SK하이닉스(000660)** 주가를 비교하고, 당일 원/달러 환율을 적용한 원화 환산 주가 및 ADR 프리미엄(괴리율, %) 추이를 시각화하는 Streamlit 대시보드입니다.

---

## 📌 주요 기능

1. **실시간 데이터 수집 & 정제**
   - 미국 나스닥 SKHY 종가 및 당일 USD/KRW 원달러 환율 (`yfinance`)
   - 국내 증시 SK하이닉스 종가 (`yfinance` & 네이버 금융 폴백)
   - 미국/한국 휴장일 차이에 따른 정합성 자동 보정 (Forward-fill)

2. **지표 계산 공식**
   - **SKHY 원화 환산 주가** = `달러 기준 주가 × 10 × 당일 환율`
   - **ADR 프리미엄 금액 (원)** = `SKHY(원화) - SK하이닉스(원)`
   - **ADR 프리미엄 율 (%)** = `((SKHY(원화) - SK하이닉스) / SK하이닉스) × 100`

3. **인터랙티브 듀얼 축 차트 시각화 (Plotly)**
   - **1. SKHY(ADR) 프리미엄 차트**:
     - 주 Y축 (좌측): SK하이닉스(원화) vs SKHY 환산주가(원화) 비교
     - 보조 Y축 (우측): ADR 프리미엄(%) 막대/꺾은선 그래프 (0% 기준선 점선 표시)
     - 차트 표현 방식 실시간 선택 지원 (꺾은선+막대 / 전체 꺾은선 / 그룹 막대+꺾은선)
   - **2. SK하이닉스 vs SKHY 주가 차트**:
     - 가공하지 않은 원본 주가 그대로 표시
     - 좌측 Y축: SK하이닉스 종가 (원화, KRW) 꺾은선
     - 우측 Y축: SKHY 종가 (달러, USD) 꺾은선
   - 일자별 데이터 창(툴팁) 투명도 슬라이더 조절 지원

4. **실시간 KPI 요약 카드**
   - 최신 SK하이닉스 종가, SKHY 주가 및 환율, 원화 환산가, 최신 프리미엄(%) 및 전일비 변동
   - 조회 기간 내 평균 프리미엄, 역대 최고치, 역대 최저치 요약

5. **원본 데이터 테이블 & 다운로드**
   - 최근 일자 순 내림차순 정렬 및 수치 포맷팅
   - `CSV 다운로드` 및 `Excel 다운로드` 지원

## 🚀 실행 방법

### 1. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. 대시보드 실행
```bash
streamlit run app.py
```
*(Windows 환경에서는 `run.bat` 파일을 더블 클릭하여 간편하게 실행할 수 있습니다.)*
